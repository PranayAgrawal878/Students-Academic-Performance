# Student Performance & Demographics Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard designed to analyze student demographics, academic performance, and study patterns.

The dashboard provides a quick overview of student-related KPIs and allows users to explore the data using interactive slicers and visualizations.

## 🎯 Objectives

- Analyze the overall student population
- Understand student demographics
- Analyze age groups and residence patterns
- Compare academic performance
- Analyze study hours and their relationship with academic performance
- Provide interactive filtering for better data exploration

## 📌 Key KPIs

The dashboard includes the following key metrics:

- **Total Students**
- **Average Age**
- **Average Study Hours**
- **Average Entrance Marks**
- **Average Python Score**
- **Average Database Score**

## 📈 Dashboard Features

### Student Demographics
- Students by Gender
- Students by Residence
- Students by Age Group
- Students by Previous Education

### Academic Analysis
- Entrance Marks
- Python Performance
- Database Performance
- Study Hours
- Relationship between Study Hours and Academic Performance

### Interactive Filters

Users can filter the dashboard using:

- Country
- Gender
- Residence
- Age Group
